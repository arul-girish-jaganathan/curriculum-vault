## Status meanings

- `AUDIT_REQUIRED` — previous work exists but completion/validation has not been independently established.
- `IN_PROGRESS` — active processing is underway.
- `REVIEW_REQUIRED` — processing exists but quality review remains.
- `VALIDATED` — automated and manual evidence supports the recorded scope.
- `NOT_STARTED` — no substantive processing has been performed.

## Rules

This ledger must be updated from actual repository evidence. Do not copy planned counts from old curriculum documents into this table.

A domain is not `VALIDATED` merely because files exist or because a previous agent reported completion.
