# Learning Status

> [!summary]
> This page answers: **What do I actually know, what is weak, and what should I learn next?**

## 1. Maturity Scale

| Level | Meaning |
|---|---|
| 0 — Unfamiliar | I have not learned the topic. |
| 1 — Recognition | I recognize the terminology and basic purpose. |
| 2 — Working | I can explain common cases and implement basic examples. |
| 3 — Senior | I can debug real problems and make informed engineering choices. |
| 4 — Staff | I can design, review, compare trade-offs, and guide others. |
| 5 — Principal-capable | I can reason about system-wide effects, uncertainty, long-term evolution, and organizational impact. |

## 2. Evidence Ladder

Use these evidence levels:

- `Read` — studied authoritative material
- `Explain` — can explain without notes
- `Implement` — implemented it
- `Debug` — debugged it in practice
- `Measure` — measured behavior/performance
- `Design` — designed with it
- `Teach` — explained it successfully to another engineer
- `Production` — used it in a real product

The strongest evidence is usually **Production + Debug + Design**.
