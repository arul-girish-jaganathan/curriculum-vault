# Source Backbone

This package is a structured, paraphrased study framework. It is not a verbatim reproduction of any single source.

## Primary references
- RFC Editor: https://www.rfc-editor.org/
- IETF Datatracker: https://datatracker.ietf.org/
- Linux networking documentation: https://docs.kernel.org/networking/
- iproute2 documentation/source: https://git.kernel.org/pub/scm/network/iproute2/iproute2.git/
- Wireshark documentation: https://www.wireshark.org/docs/
- tcpdump/libpcap: https://www.tcpdump.org/
- lwIP documentation: https://www.nongnu.org/lwip/
- FreeRTOS documentation: https://www.freertos.org/
- Zephyr networking documentation: https://docs.zephyrproject.org/latest/connectivity/networking/index.html
- DPDK documentation: https://doc.dpdk.org/
- eBPF/XDP documentation: https://docs.kernel.org/bpf/
- AUTOSAR: https://www.autosar.org/
- CAN in Automation: https://www.can-cia.org/
- Bluetooth SIG: https://www.bluetooth.com/specifications/
- Wi-Fi Alliance: https://www.wi-fi.org/
- LoRa Alliance: https://lora-alliance.org/
