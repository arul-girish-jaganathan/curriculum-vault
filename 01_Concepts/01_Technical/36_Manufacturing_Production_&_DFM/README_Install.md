# Manufacturing / Production / DFM Obsidian Knowledge Base

A 90-chapter canonical textbook for manufacturing engineering, production, DFM/DFA/DFT, electronics/mechanical processes, quality engineering, NPI, supplier quality, factory automation, traceability, validation, and Staff-level manufacturing leadership.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep product-specific drawings, BOMs, process flows, PFMEA, control plans, PPAP packages, NCRs, 8D/CAPA, yield reports, supplier findings, and factory data in project notes and link them back to these canonical concepts.

This is a study/reference framework; actual production decisions must follow the applicable controlled specifications, drawings, customer requirements, quality system, and regulatory obligations.
