# OS Textbook — Obsidian 90 Chapters / Complete Topic Map

90 chapter folders × 12 canonical topic notes = 1,080 topic notes.

Coverage:
- OS foundations, kernel, system calls and boot
- processes, PCBs, creation/termination and fork/exec/wait
- CPU scheduling from FCFS/SJF/RR through MLFQ and multiprocessor scheduling
- threads, concurrency, synchronization and deadlocks
- IPC: pipes, queues, shared memory, signals and sockets
- memory allocation, paging, segmentation and virtual memory
- TLBs, page replacement, working sets, COW, huge pages and NUMA
- file systems, VFS, inodes, journaling, allocation and free-space management
- storage/I/O, drivers, interrupts and DMA
- protection, security, virtualization and distributed OS
- performance/debugging/observability
- OS architecture and Staff-level reasoning
