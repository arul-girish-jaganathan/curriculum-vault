# Systems Engineering & Requirements Obsidian Knowledge Base

A 90-chapter canonical textbook for systems engineering and requirements engineering across embedded and complex products.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep project-specific requirements, ConOps, allocation matrices, ICDs, trade studies, architecture baselines, verification matrices, system-test evidence, and review records in project notes and link them back to these canonical concepts.

This is a study/reference framework, not a substitute for controlled organizational processes, contractual requirements, regulations, or applicable standards.
