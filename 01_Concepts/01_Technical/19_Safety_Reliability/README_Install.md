# Safety Reliability Obsidian Knowledge Base

A 90-chapter canonical textbook for embedded Safety and Reliability engineering.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep project-specific safety cases, FMEA/FTA, test evidence, field failures, and interview notes outside the canonical concept notes and link them back to these concepts.

The scope spans functional safety, reliability engineering, fault analysis, safety integrity, automotive/industrial/aerospace/medical standards, safe C/C++, verification, fault injection, real-time safety, MCU/SoC safety mechanisms, field reliability, and Staff-level safety/reliability architecture.
