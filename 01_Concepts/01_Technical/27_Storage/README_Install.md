# Storage Obsidian Knowledge Base

A 90-chapter canonical textbook for embedded and systems storage.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep project-specific partition maps, filesystem choices, media qualification, performance traces, corruption incidents, power-cut results, and field-health findings in project notes and link them back to these canonical concepts.

The scope spans memory/flash media, storage controllers, Linux block/MTD/VFS layers, filesystems, performance, endurance, reliability, security, power-loss integrity, OTA, manufacturing, field diagnostics, and Staff-level storage architecture.
