# Source Backbone

This package is a structured, paraphrased study framework. It is not a verbatim reproduction of any single source.

## Primary references
- MIT OpenCourseWare Control Systems Engineering resources: https://ocw.mit.edu/
- MIT OpenCourseWare Feedback Systems: https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/
- University of Michigan Control Tutorials: https://ctms.engin.umich.edu/
- Stanford / Brian Douglas control resources: https://www.youtube.com/@BrianBDouglas
- Åström & Murray, Feedback Systems: https://fbswiki.org/
- SciPy signal processing/control-adjacent numerical tools: https://docs.scipy.org/doc/scipy/
- NumPy linear algebra: https://numpy.org/doc/
- CMSIS-DSP: https://arm-software.github.io/CMSIS-DSP/
- Arm Developer Documentation: https://developer.arm.com/documentation
- MATLAB Control System Toolbox documentation: https://www.mathworks.com/help/control/
- Simulink documentation: https://www.mathworks.com/help/simulink/
