# Power_Thermal_Circuits Obsidian Knowledge Base

A 90-chapter engineering textbook covering electrical circuits, power conversion, power integrity, EMI/EMC, thermal analysis, cooling, battery power, PMICs, embedded power rails, low-power firmware, measurement, SPICE, debugging, verification, reliability, and Staff-level power/thermal architecture.

Use `00_Complete_Topic_Map.md` as the main navigation page. Keep project-specific measurements, schematics, thermal images, failure reports, and bring-up notes in project folders and link them back to these canonical concepts.
