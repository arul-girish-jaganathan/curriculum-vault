# System Design Obsidian Knowledge Base

A 90-chapter canonical textbook for embedded and systems architecture/design.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep project-specific architecture documents, ADRs, design reviews, trade studies, and case studies outside the canonical concept notes and link them back to these concepts.

The scope spans requirements, architecture, interfaces, embedded/RTOS/Linux design, communication, storage, concurrency, performance, resilience, security, safety, testability, lifecycle, manufacturing, field service, and Staff-level system design.
