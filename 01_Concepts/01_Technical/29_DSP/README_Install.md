# DSP Obsidian Knowledge Base

A 90-chapter canonical textbook for Digital Signal Processing across signal theory, sampling, FFT/filtering, fixed/floating point, multirate processing, adaptive DSP, communications, embedded/real-time DSP, MCU/DSP processors, SIMD, DMA, performance, validation, audio, sensing, vibration, imaging, and Staff-level architecture.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep project-specific signal chains, measurement captures, filter coefficients, performance traces, and algorithm decisions in project notes and link them back to these canonical concepts.
