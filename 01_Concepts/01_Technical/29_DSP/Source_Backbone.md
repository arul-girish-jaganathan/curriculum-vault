# Source Backbone

This package is a structured, paraphrased study framework. It is not a verbatim reproduction of any single source.

## Primary references
- MIT OpenCourseWare Signals and Systems: https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/
- MIT OpenCourseWare Digital Signal Processing: https://ocw.mit.edu/courses/6-341-discrete-time-signal-processing-fall-2005/
- Stanford CCRMA DSP resources: https://ccrma.stanford.edu/~jos/
- Julius O. Smith, DSP resources: https://ccrma.stanford.edu/~jos/
- NumPy FFT and signal-processing documentation: https://numpy.org/doc/
- SciPy signal-processing documentation: https://docs.scipy.org/doc/scipy/reference/signal.html
- CMSIS-DSP documentation: https://arm-software.github.io/CMSIS-DSP/
- Arm Developer Documentation: https://developer.arm.com/documentation
- Texas Instruments DSP resources: https://www.ti.com/
- Analog Devices DSP resources: https://www.analog.com/
- Microchip dsPIC/DSP resources: https://www.microchip.com/
