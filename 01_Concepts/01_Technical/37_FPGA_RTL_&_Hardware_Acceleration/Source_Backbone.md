## Current-source note
AMD's current 2026.1 Vivado documentation explicitly covers RTL design, synthesis, placement/routing, timing analysis, hardware debug/validation, IP integration, and Tcl/project flows. cocotb's current documentation describes Python-based cosimulation with common simulators and CI-oriented test reporting.
