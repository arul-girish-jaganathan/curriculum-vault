# Digital Electronics & Computer Hardware Obsidian Knowledge Base

A 90-chapter canonical textbook for digital electronics, computer hardware, embedded hardware boundaries, buses, memory, FPGA/RTL, timing, signal integrity, power integrity, debug, validation, and Staff-level hardware engineering.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep board-specific schematics, waveforms, register notes, bring-up logs, hardware changes, and lab evidence in project notes and link them back to these canonical concepts.
