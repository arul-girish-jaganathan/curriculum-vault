# Source Backbone

Primary/reference families used to shape the curriculum:

- Linux kernel networking documentation — networking stack, SocketCAN, networking APIs, IPv6, Netlink.
- USB-IF specifications and supplements — USB architecture, transfers, endpoints, errors, SuperSpeed.
- CAN in Automation (CiA) — CAN/CAN FD/CAN XL terminology, arbitration, CRC and protocol evolution.
- IETF RFCs and protocol specifications — IP, TCP, UDP, QUIC, DHCP, DNS, TLS, HTTP and related Internet protocols.
- AUTOSAR and automotive ecosystem specifications for diagnostic/vehicle communication topics.
- IEEE/ISO protocol families for Ethernet, CAN, time-sensitive networking and industrial/automotive communications.

Web source checks used for scope validation:
Linux networking docs: https://docs.kernel.org/networking/index.html
Linux IPv6 docs: https://docs.kernel.org/networking/ipv6.html
Linux networking APIs: https://docs.kernel.org/networking/kapi.html
Linux Netlink intro: https://docs.kernel.org/userspace-api/netlink/intro.html
CAN in Automation CAN XL: https://can-cia.org/can-knowledge/can-xl
USB-IF embedded USB2 supplement: https://www.usb.org/

The notes are a structured personal knowledge base. They are not reproductions of standards text.
