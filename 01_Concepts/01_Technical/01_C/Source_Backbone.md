# Source Backbone

Primary references used to shape the curriculum; notes are original study material, not copied source text.

- ISO C / WG14: https://www.open-std.org/jtc1/sc22/wg14/
- C language overview and tutorials: https://www.geeksforgeeks.org/c-programming-language/
- C reference: https://en.cppreference.com/w/c
- CERT C secure coding: https://wiki.sei.cmu.edu/confluence/display/c
- SEI CERT C coding standard and guidance
- GCC documentation: https://gcc.gnu.org/onlinedocs/
- Clang documentation: https://clang.llvm.org/docs/

## Scope
The package is organized as a durable C reference for embedded engineers. Where behavior depends on compiler, ABI, libc, CPU, MCU, RTOS, or project policy, the notes call that distinction out explicitly.
