# Security Obsidian Knowledge Base

A 90-chapter canonical textbook for embedded and systems security.

Use `00_Complete_Topic_Map.md` as the navigation surface. Link projects, security reviews, CVE notes, incidents, mistakes, and interview material back to these canonical security concepts instead of duplicating the knowledge.

The scope spans secure C/C++, cryptography, secure boot, TrustZone, firmware security, Linux security, network/protocol security, OTA, supply chain, testing, monitoring, incident response, and Staff-level security architecture.
