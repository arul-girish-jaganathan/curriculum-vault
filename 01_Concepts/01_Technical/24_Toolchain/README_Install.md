# Toolchain Obsidian Knowledge Base

A 90-chapter canonical textbook for compiler, assembler, linker, debugger, build-system, embedded SDK, binary-analysis, and firmware-release toolchain engineering.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep project-specific build failures, toolchain migrations, binary investigations, CI problems, and architecture decisions in project notes and link them back to these canonical concepts.
