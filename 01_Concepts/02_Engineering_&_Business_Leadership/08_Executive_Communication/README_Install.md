# Executive Communication Obsidian Knowledge Base

A 90-chapter canonical textbook for Executive Communication aimed at the long-term Staff → Principal → Engineering Executive → CEO leadership path.

Use `00_Complete_Topic_Map.md` as the primary navigation surface. Keep actual board decks, CEO memos, customer escalations, crisis communications, QBRs, all-hands scripts, and personal leadership reflections in project/leadership notes and link them back to these canonical concepts.
